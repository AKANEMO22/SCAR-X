# Phase 2 v1: local synaptic learning and retention

Registered before first execution. Configuration: configs/phase2.json.

- Seeds 17, 29, 43. Five conditions share initial seed/config except rate neurons.
- 512 training episodes, 128 held-out episodes. Train noise seed 1000+seed; test 2000+seed.
- Separate delayed recall: train delay 4, test delays 4 and 8. Reset neural state before every episode. No retrieval.
- Reversal: retain the first task's trained model, train 512 examples with shifted labels; report old and new rule performance. Contradictory rules without a context cue cannot both be correct.
- Continual: 20 distinct context cues, context-specific fixed permutations. 64 new examples/stage, 32 held-out examples/task, bounded reservoir replay (128 episodes, 32 replays/stage). Replay and consolidation are disabled in frozen condition.
- Full vs frozen is a learning check; full vs readout-only isolates evidence for hidden plasticity. A full-vs-frozen gain alone cannot prove hidden plasticity helps.
- Retention: for every task, maximum score attained after learning minus final score. Report mean and worst task after stage 20; thresholds .03/.05. No current-task training examples enter test.
- 95% paired seed-cluster bootstrap intervals; only 3 seeds, exploratory. Require lower interval >= .10 vs frozen for learning; lower interval > 0 vs readout-only for hidden contribution.
- Gate to language: learning check, hidden contribution, delayed score above chance, retention limits for every seed, checkpoint restart parity, observed memory <=2 GB. Missing controls or missing 8h endurance are reported; no commercial claims.
- Stop growth if this gate fails. No hyperparameter tuning on these test examples. A second protocol requires a new development set and rationale before execution.
- Conditions with an analog rate neuron or future backprop control are research controls, never imported into the main core.
- Source: programmatically generated by tasks.py, repository-authored; noise seeds and generator version constitute the data manifest.
